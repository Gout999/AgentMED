## 项目名称（20 字）

AgentMED：AI 应用完整质量闭环

## 文字说明（493 字）

现在，AI 应用越来越多——大量软件都嵌有 AI 生成部分。一条坏结果出现时，是代码错了、Prompt 变了、模型漂移了，还是索引过期了？从投诉到修复再到放行的完整闭环是缺失的。

AgentMED 补的正是这条链路。投诉进来走七段闭环：立案→取证→归因→修复→沙箱验证→人工放行→部署观察与回滚；证据不足就诚实停下，绝不假装成功。

三层分工是差异所在：Agent 团队动脑——六角色跑在 AgentTeams，复用平台原生 skills/MCP；控制面守规矩——状态机与 nonce 不可绕过；人类授权——房间一键批准。原生 A2A：软件管理者用熟悉的 Agent 即可提交投诉、跟踪案件、审批候选，软件本身成为可审批的对象。

这不是 PPT：一句「昨天还说 7 天无理由，今天就说激活不能退」的投诉进来，取证、归因把问题钉在 Prompt 一层，修复候选经沙箱独立验证、人工放行，停在 VerifiedCandidate——修好了、留了证，但没有未经观察就上线。

开源开放：治理能力以 A2A 开放，外部 Agent 可调用审批与查询；六角色团队已部署真实AgentTeams并全链跑通留证。
